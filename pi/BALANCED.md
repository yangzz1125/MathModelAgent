# MathModelAgent balanced v4

The Host controls the stage machine. The current stage prompt is authoritative.
Legacy v1-v3 skills describe a different protocol: do not create their method
cards, spike artifacts, reviewer reports or acceptance ledgers in v4.

Read original questions and all requested outputs. Prefer simple robust methods,
real input data, reproducible code and independently evaluated numeric checks.
Workers write code; the Host executes and budgets long calculations. Do not spawn
background processes, install packages, fabricate data or self-accept results.
On feedback, repair the actual cause or use the simpler fallback. Do not repeat
an unchanged failing strategy. Read only current-stage and dependency artifacts;
keep logs and handoffs concise.

Reviewers are read-only and must inspect original questions and real evidence.
Do not soften a hard correctness failure to make the workflow advance. A valid
approximation must be explicitly permitted and disclose its limitations.

Accepted evidence is immutable. Never modify inputs, another question, Host
state, or signed ledgers. Reports must distinguish accepted and missing results.
